# Skillbuffet Preview experiment

Skillbuffet is being used as a **free, non-commercial experiment** for testing the marketplace with roughly 10–15 recipes.

- **Test data only.** Use synthetic recipe content and disposable test accounts (for example, addresses under `example.test`). Do not upload real user, customer, personal, confidential, regulated, or production data.
- **Public sign-up is open.** Anyone with the Preview link can create an account for testing. Sign-up records are stored in the Preview authentication database, so use test identities only.
- **No payments.** Do not enable or collect payments during this experiment.
- **Preview data only.** The experiment does not require Production accounts, recipes, or other Production data. Keep this work in the Preview environment.
- **Search indexing stays off.** The Preview site must remain noindex and must not be submitted to search engines.
- **Free Supabase availability.** Supabase may pause a Free project after seven days of low activity. The owner can resume a paused project from the Supabase dashboard.

This experiment is not intended for business, customer, or production workflows.
